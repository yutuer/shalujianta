# 虎 的卡牌截图

把这一角色 **5 张卡**的**满级状态**截图放这个目录。
**文件名 = 卡面上的名字**（照卡存就行，不用记 cardId）：

- `猛虎下山.png` ← cardId `tiger_attack`（现状：伤害 15，费用 2）
- `虎踞龙盘.png` ← cardId `tiger_defense`（现状：护盾 8，费用 1）
- `虎啸山林.png` ← cardId `tiger_special`（现状：伤害 10，费用 2）
- `猛虎下山.png` ← cardId `tiger_special2`（现状：伤害 16，费用 2）
- `虎视眈眈.png` ← cardId `tiger_special3`（现状：伤害 8，费用 1）

> 截图要求：① 卡面**完整全图**（不裁掉卡名/费用角标/类型图标/描述/等级角标）② 满级状态 ③ 有词条的展开 tooltip ④ 5 张摆一起的合影

详见 [docs/卡牌设计.md](../../卡牌设计.md) §2。
