# 兔 的卡牌截图

把这一角色 **5 张卡**的**满级状态**截图放这个目录。
**文件名 = 卡面上的名字**（照卡存就行，不用记 cardId）：

- `蹬鹰一脚.png` ← cardId `rabbit_attack`（现状：伤害 8，费用 1）
- `狡兔三窟.png` ← cardId `rabbit_defense`（现状：，费用 1）
- `疾如风.png` ← cardId `rabbit_special`（现状：，费用 0）
- `静若处子.png` ← cardId `rabbit_special2`（现状：护盾 5，费用 1）
- `兔起凫举.png` ← cardId `rabbit_special3`（现状：伤害 12，费用 2）

> 截图要求：① 卡面**完整全图**（不裁掉卡名/费用角标/类型图标/描述/等级角标）② 满级状态 ③ 有词条的展开 tooltip ④ 5 张摆一起的合影
