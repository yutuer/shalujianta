# 卡牌设计总表（角色特色化）

> 目标：**每个角色一组自己特有的卡牌**，让战斗玩起来有区分度。
> 本文件是**设计落点**：主人按参考游戏截图给「满级卡牌状态」，我逐张转成数据表条目。
>
> 最后更新：2026-10-23（D29 把数据表接进战斗后盘点）

---

## 1. 现状盘点（已实测量过）

### 1.1 已经有了什么

`Data/character_cards.json` 里 **96 张卡**（12 可玩角色 × 5 + 12 星座 BOSS × 3），
每张都带：卡名 / 类型 / 费用 / 是不是攻击 / 伤害 / 护盾 / 抽牌 / 能量 / 增益 / 减益 / 怒气成长 / 等级系数，
并且**每张都有独立的插画**（`Assets/Cards/card_<cardId>.svg`）。
**D29 已经把这张表接进战斗**（此前队伍卡组是代码硬编码的，12 张特殊技全是空牌）。

### 1.2 为什么还是「不够丰富」——四个缺口

| # | 缺口 | 证据 |
| :--: | :--- | :--- |
| 1 | **机制太扁平**：60 张可玩卡只用到 8 种效果（伤害 / 护盾 / 抽牌 / 能量 / 中毒 / 虚弱 / 群体 / 力量）。羊的 3 张特殊卡**全是护盾**、狗的 3 张特殊卡**全是护盾+能量**、猪的 3 张特殊卡**全是护盾** —— 换角色只是换数字，不是换玩法 | 见 §4 总表 |
| 2 | **名字撞车 3 处** | `rat_defense` 与 `rabbit_defense` 都叫「狡兔三窟」；`tiger_attack` 与 `tiger_special2` 都叫「猛虎下山」（伤害 15 / 16）；`monkey_special` 与 `monkey_special2` 都是「猴王戏…」 |
| 3 | **升级系统是空壳**：`Card.Level` 1~6、伤害每级 +20%、`CardUpgradeInfo.AddExp` 都写好了，但**全项目没有任何地方给卡牌加经验**（`AddExp` 零调用点）→ 「满级卡牌」现在在游戏里**根本到不了** | `Card.cs` / `CardLevelSystem.cs` 有实现，`AddExp` 无调用者 |
| 4 | **BOSS 的 36 张卡完全没进游戏**：敌人现在只有 HP / ATK / 意图图标，**不会出牌** | `Data/character_cards.json` 里 36 张 BOSS 卡只有美术被用上 |

### 1.3 数值等级口径（满级截图的反推依据）

现成的成长公式在 `CardLevelSystem.cs`：

| 类型 | 公式 | 6 级 = 1 级的几倍 |
| :--- | :--- | :--- |
| 伤害 / 护盾（属性联动） | `值 × 系数 × (1 + 0.2 × (等级-1))` | **×2.0** |
| 抽牌 / 能量 / 增益数值（固定值） | `基础 + 每级 × (等级-1)` | 基础 + 5×每级 |
| 怒气 | `5 + 每级 × (等级-1)`（战斗实际发 15/10，见 D30） | — |

> ⚠️ 战斗里**怒气实际发的是硬编码的 15（攻击）/ 10（防御）**，
> 卡面显示的却是「5 + 每级成长」—— **这两个口径还没对齐**，做卡牌数值时要注意。

## 2. 我需要主人提供的截图规格

**每张卡一张截图**，要拍到（缺一项我就要靠猜）：

| # | 必须包含 | 为什么 |
| :--: | :--- | :--- |
| 1 | **卡面完整全图**（不要裁掉卡名、费用角标、类型图标、描述全文、等级角标） | 卡面文字是**从数据自动生成**的（`DescriptionGenerator`），描述写成什么样取决于数据字段怎么填 |
| 2 | 卡牌处于**满级**时的状态 | 满级数值是锚点，1~5 级我按 §1.3 的公式反推 |
| 3 | 卡牌有**词条 / 状态**时的展开 tooltip 图 | 词条字段（减益、增益、特殊规则）现在数据表里没有对应字段，可能要加 |
| 4 | **一个角色 5 张摆一起**的图 | 方便我确认哪张对应哪个 `cardId` |

**分组建议**：一个角色一批（5 张），我按角色逐批落地并验证，做完一个角色就能试玩一次。
