# 新角色接入指南

> 造一个可玩角色的完整清单。**照着这份清单做，第二个、第三个角色都一样的流程。**
> 第一次做是波吕克斯（见 `docs/开发计划.md` D32 + D41），本文件把那次边做边摸索的过程固定下来。

## 一、主人要提供的截图

放在 `docs/screenshots/人物_<角色名>/`（**目录名 = 角色名**，和波吕克斯那套一致）。

| # | 文件名 | 从图里能读出什么 | 缺了会怎样 |
| :--: | :--- | :--- | :--- |
| 1 | `人物列表_<名>.jpg` | **角色类型**（伤害型 / 辅助型 / 防御型）、角色名 | 列表页显示不出类型 |
| 2 | `详细属性_<名>.jpg` | 全部属性：体力 / 攻击 / 防御 / 体质 / 暴击率 / 暴击伤害 / 界域精通 / 伤害强效 / 基础狂气 / 狂气回充等级 / 银钥充能等级 / 黑印掉落 / 死亡抵抗 | 属性面板只能填猜的 |
| 3 | `卡牌总览_<名>.jpg` | 5 张卡的**整体**：卡名 / 费用 / 等级 / 类型 / 正文 / 词缀 | 要一张张看 |
| 4 | `卡牌1_<名>.jpg` ~ `卡牌5_<名>.jpg` | 每张卡的卡面细节（正文全文、词缀） | 正文只能抄概览图上的 |
| 5 | `卡牌1_技能升级_<名>.jpg` ~ `卡牌5_技能升级_<名>.jpg` | **每张卡右侧「属性」面板**：伤害 攻击力×N% / 护盾 防御力×N% / 狂气值 | ⚠️ **最关键** —— 这是算 1~6 级数值的**硬证据**（面板给系数、卡面给结果值，两者交叉反推） |
| 6 | `大招_技能升级_<名>.jpg` | **必杀技**：名字 / 描述 / 伤害系数 / 效果 / 属性面板 | 必杀技只能瞎编 |
| 7 | `天赋1_<名>.jpg` | 天赋（每级效果） | 天赋留空 |
| 8 | `卡牌_衍生1_<名>.jpg`（有衍生卡才有） | 衍生卡的完整规格 | 衍生卡不做 |

> **数值反推方法**见 [`卡牌设计.md`](卡牌设计.md) §6.2（波吕克斯那 5 张卡 + 必杀技的实测表）——
> 同样的算法照搬到新角色即可。

## 二、我这边要改的 5 处

| # | 文件 | 改什么 | 注意 |
| :--: | :--- | :--- | :--- |
| 1 | `Data/characters.json` | **+1 条**：characterId / name / nameEn / race / baseHealth / baseEnergy / baseDrawCount / baseAttack / baseDefense / baseConstitution / baseCritRate / baseCritDamage / attackCardId / defenseCardId / specialCardIds[3] / ultimateSkillId | `race` 可留空（12 生肖都空，波吕克斯是 `chaos`）；**立绘不用填** —— 代码按 `char_<characterId>.svg` 自动推导 |
| 2 | `Data/character_cards.json` | **+5 条**：打击 / 防御 / 3 张专属 | 每张要有 `effects[]`（唯一真相源）、`affixes`、`cardType`、`damageBaseCoefficient` 等；**打击/防御必须各角色独立**（`check-card-data.ps1` 守着） |
| 3 | `Data/ultimates.json` | **+1 条**：skillId / characterId / name / nameEn / description / rageCost / damagePercent(或 damage) / damageBaseCoefficient / isAreaAttack | 百分比口径：伤害 = 角色攻击 × 百分比，**不乘等级系数** |
| 4 | `tools/generate-card-art.ps1` | `$AllPalette` + `$charOrder` 各加一条（角色配色） | 脚本**默认不覆盖已存在文件** → 跑一次只会补生成新角色的 5 张卡插画 + 圆形头像 |
| 5 | `tools/generate-placeholder-svg.ps1` | `$Characters` 加一条（立绘造型/配色） | 这张表是**硬编码**的，不加就不会有 `char_<id>.svg` |

跑完脚本后要 `Godot.exe --headless --path <项目> --import` 生成 `.import`（否则运行时 No loader found）。

## 三、校验与实测

**数据层**
```powershell
powershell -ExecutionPolicy Bypass -File tools\check-card-data.ps1      # 每角色 2 张独立基本卡 / effects[] 一致
powershell -ExecutionPolicy Bypass -File tools\check-doc-consistency.ps1
powershell -ExecutionPolicy Bypass -File tools\check-task-stats.ps1
```

**运行时**（godot-runtime MCP，`background: true`）
- 角色一览**列表页**：新角色出现在网格里，名字 / 类型 / 头像正确
- 角色一览**详情页**：立绘 / 属性 / 5 张卡等级 / 天赋
- **卡牌总览页**：必杀技说明（数值与战斗同源）+ 5 张卡正文 + 词缀着色
- **战斗**：进战斗 → 队伍里有他 → 打出卡 → 数值与卡面一致（**卡面写 37 实际就得打 37**）

**提交前必还原**
- `Scripts/Dev/DevScenario.cs` 的 `presetKey` 改回 `"default"`
- `git checkout -- project.godot`（MCP 会注入 `McpBridge` autoload）

  项目文档一律用「必杀技」，参考图上的叫法是「狂气爆发」。

  `docs/开发计划.md`（新增条目 + §3 总表 + §6 统计）、`docs/卡牌设计.md`（角色机制/天赋/数值实测表）、
  `README.md`（变更记录 + 数字）、`docs/会话交接.md`（进度快照）、`docs/踩坑记录.md`（新坑）。
