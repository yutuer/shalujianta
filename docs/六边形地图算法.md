## 坐标系统

项目使用 **axial 坐标** (Q, R) 系统，冗余轴 `S = -Q - R`。

## 六边形形状

- **上下各为一个顶点**（V0 顶部、V3 底部），**左右各为一条垂直平边**（b 边与 e 边，边长 78）
- **顶点定义**（相对于 Control 左上角）:

  ```
  V0 = (90, 0)    - 顶部
  V1 = (165, 39)  - 右上
  V2 = (165, 117) - 右下
  V3 = (90, 156)  - 底部
  V4 = (15, 117)  - 左下
  V5 = (15, 39)   - 左上
  ```

> 边长并非处处相等：4 条斜边长 `√(75²+39²) ≈ 84.5`，2 条垂直边长 78。
> 该形状是「上下为顶点、左右为平边」的六边形，与 `.trae/rules/project_rules.md` 里
> 「扁顶 (flat-top)，顶点左右」的旧表述相反——**以本文顶点表和 `HexTileView.UpdateHexShape()` 为准**。

## 边的定义

```
a (左上): V5→V0 = (15,39)→(90,0)
b (左中): V4→V5 = (15,117)→(15,39) - 垂直左边
c (左下): V3→V4 = (90,156)→(15,117)
d (右下): V2→V3 = (165,117)→(90,156)
e (右中): V1→V2 = (165,39)→(165,117) - 垂直右边
f (右上): V0→V1 = (90,0)→(165,39)
```

## 边 ↔ 方向 对应关系

六条边与 `HexCoord` 的六个方向**一一对应**，相邻格子正好共边（已逐条验算）：

| 边 | 位置 | 共边的相邻方向 | 方向增量 (Q, R) |
| :-- | :--- | :--- | :--- |
| a | 左上 | North | (0, -1) |
| b | 左中（垂直） | NorthWest | (-1, 0) |
| c | 左下 | SouthWest | (-1, 1) |
| d | 右下 | South | (0, 1) |
| e | 右中（垂直） | SouthEast | (1, 0) |
| f | 右上 | NorthEast | (1, -1) |

## 坐标转换公式

### Axial → 世界坐标

```
x = 150 * Q + 75 * R
y = 117 * R
```

### 世界坐标 → Axial

```
R = round(y / 117)
Q = round((x - 75 * R) / 150)
```

> 代码实现（`HexMapUI.WorldToHex`）会先减去**视口中心**再套公式，因为地图容器始终跟随玩家居中。

## HexCoord 方向向量

| 方向 | Q, R 增量 | 说明 |
|------|----------|------|
| North | (0, -1) | 正北 |
| South | (0, 1) | 正南 |
| NorthEast | (1, -1) | 东北 |
| NorthWest | (-1, 0) | 西北 |
| SouthEast | (1, 0) | 东南 |
| SouthWest | (-1, 1) | 西南 |

## 六边形尺寸

**Control 尺寸**（`_hexSize`，即 `tileView.Size`）：
- 宽 180px × 高 156px
- 中心点：(90, 78)

**实际绘制的多边形范围**（`HexTileView.UpdateHexShape()` 顶点）：
- x ∈ [15, 165]（宽 150px），y ∈ [0, 156]（高 156px）
- 即左右各留 15px 边距；多边形自身左右两侧为垂直平边

**排布间距**：
- 水平间距：150px（相邻列 Q+1 的 x 差）
- 垂直间距：117px（同行 R+1 的 y 差）
- 行内错位：75px（相邻行的 x 偏移 = 水平间距 ÷ 2）

> 校验：把当前格子的 b 边（x=15, y 39~117）平移 `(-150, 0)`，恰好等于
> NorthWest 邻居的 e 边（x=15, y 39~117）——六边共边严丝合缝。
> 边与方向的对应关系已用脚本逐条验算：每条边恰好对应 1 个方向，6 条边覆盖 6 个不同方向。

## 示例：添加新六边形

假设要在 Hex7 (2, -2) 的右上方向添加新六边形：

```
Hex7 = (2, -2)
新坐标 = Hex7 + NorthEast = (2+1, -2-1) = (3, -3)

屏幕位置:
x = 150*3 + 75*(-3) = 225
y = 117*(-3) = -351

Control 位置 = (400+225, 300-351) = (625, -51)
```

（以 Hex0 的 Control 位置 `(400, 300)` 为基准换算）
